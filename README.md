# Web Python 2026 - Лабораторні роботи

Цей репозиторій містить виконання 5-ти лабораторних робіт з курсу "Web Python". 
Предметна галузь системи обробки даних: **ІС «Стоматологічний кабінет»**.

У ході лабораторних робіт було створено декілька варіантів серверних додатків, використовуючи різні фреймворки (FastAPI, Django) та різні бази даних (SQLite, PostgreSQL, MongoDB). Даний репозиторій повністю підготовлений до завантаження на GitHub.
